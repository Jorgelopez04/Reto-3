The ArcGIS Administrator

The ArcGIS Administrator Wizard helps you administer your ArcGIS Desktop and provides valuable information about your installation. With it, you can perform tasks such as

  • Borrowing and returning licences from a license manager
  • Switching your software product between concurrent-use Advanced (ArcInfo), Standard (ArcEditor), and Basic (ArcView), or single-use products
  • Changing the license manager
  • Viewing license availability
  • Launching the Authorization Wizard for single-use products

Note:

Although you can switch the product type for concurrent use, a license for that product must be present and available for the applications to open and function.

The ArcGIS Administrator Wizard is only launched the first time you install ArcGIS Desktop. After you have completed the ArcGIS Administrator Wizard, you can access the ArcGIS Administrator by clicking Start > Programs > ArcGIS > ArcGIS Administrator.

  • Select Desktop to perform the following tasks:
    • Borrow and return licences from a license manager
    • Switch your software product between concurrent-use Advanced (ArcInfo), Standard (ArcEditor), and Basic (ArcView), or single-use products
    • Change the license manager
    • View license availability
    • Launch the Authorization Wizard for single-use products
  • Select Availability to view the status of your product registration/licensing.

Citrix Users

  • Users running ArcGIS Desktop on Citrix or Windows Terminal Services can create a user environment variable ESRI_SOFTWARE_CLASS with a value of the product you need to run.

The value options are

  • Viewer for Basic
  • Editor for Standard
  • Professional for Advanced

Note:

If you do not have the proper permissions, the ArcGIS Administrator will not allow you to change product types or the license manager. Create and delete permissions are required for the following registry hives to change seat type and license manager:

  1. HKEY_CLASSES_ROOT\CLSID
  2. HKEY_LOCAL_MACHINE\SOFTWARE\ESRI
