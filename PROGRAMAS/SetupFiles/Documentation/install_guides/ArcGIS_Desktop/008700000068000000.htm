Installing a localized ArcGIS Desktop setup

Running setup.exe provides a fully localized installation experience. Setup.exe is a bootstrapper executable that will run the main product setup.msi and then run the language pack setup.msi as a secondary installation. For example, when you run setup.exe for ArcGIS Desktop Spanish, both the Desktop setup and Spanish language pack setups will be installed. Additional language packs may be installed separately.

Setup.exe runs the ArcGIS Desktop setup and automatically installs the language pack. An Add/Remove program item will exist for each setup. The ArcGIS Desktop uninstallation process does not uninstall language packs.

ArcGIS for Desktop supports the following languages:

  • Arabic
  • Chinese
  • Finnish
  • French
  • German
  • Italian
  • Japanese
  • Brazilian Portuguese
  • Russian
  • Spanish
  • Turkish

Upgrading a localized 10.3 - 10.7.1 setup

Running setup.exe for a localized 10.8 setup will upgrade both the main product installation and the language pack installation.

If you have localized Desktop 10.3 - 10.7.1 installed and run the upgrade for the English 10.8 setup, only the core Desktop installation will be upgraded. The language pack will be retained in the original installation location. When the 10.8 language pack is available, run its setup to also upgrade the language pack to 10.8.
