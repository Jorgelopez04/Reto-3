Installing ArcGIS Desktop Developer Resources

The Developer Resource setups require that ArcGIS Desktop is already installed. The following ArcGIS Desktop Developer Resources setups are available:

  • ArcObjects SDK for the Microsoft .NET Framework
  • ArcObjects SDK for the Java Platform

Starting with the ArcGIS Desktop 10.5 release, Microsoft Visual Basic for Applications (VBA) is no longer supported. It is recommended that existing Microsoft VBA users continue to use ArcGIS Desktop version 10.2.2 or earlier, or migrate VBA customizations to ArcMap add-ins, ArcPy scripts, or ArcGIS Pro add-ins built with the Pro SDK for .NET.
