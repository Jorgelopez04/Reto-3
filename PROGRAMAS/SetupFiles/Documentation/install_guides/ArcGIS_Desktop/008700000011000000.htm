Adding tutorial data

Tutorial data for ArcGIS Desktop is available as a separate download from MyEsri.

To download the data:

  1. Log in to My Esri.
  2. Click My Organizations and then click Downloads.
    Note:

    If a Downloads tab does not appear under the My Organization tab in My Esri, click the Request Permissions side tab and ask for software download permission. The request will be processed by Esri Customer Service.

  3. Click Data and Content and then navigate to the ArcGIS Desktop tutorial data set and click Download.
