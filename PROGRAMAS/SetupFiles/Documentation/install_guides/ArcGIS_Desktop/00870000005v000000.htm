Authorizing your Software

Authorization information

Single Use products require authorization of the software for use on individual machines. You will need the authorization codes that Esri Customer Service (http://www.esri.com/about-esri/contact) sent to the contact email address referenced in the sales order. This email included the authorization codes that have been issued for each license in the order. For an ArcGIS Desktop Single Use product, the authorization code starts with the letters ESU or EVA, followed by nine numeric digits (for example, ESU123456789).
