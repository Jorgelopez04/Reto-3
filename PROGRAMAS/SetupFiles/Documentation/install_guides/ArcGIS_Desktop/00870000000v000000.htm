Installing ArcGIS Desktop from a network server

If a network server installation of ArcGIS Desktop exists, other users can install from it.. The steps below are only for those users who will be installing from a network server location.

  1. See your system administrator for the location of the network server installation. Use Windows Explorer to navigate to the folder containing the setup program, setup.exe.

    The product type can be changed after installation by accessing the ArcGIS Administrator. See The ArcGIS Administrator for further information.

  2. Double-click the setup program, setup.exe.
  3. When the installation starts, follow the instructions on your screen.

    See Installing ArcGIS Desktop on your computer for installation details.

After installation, the ArcGIS Administrator Wizard is launched. Use the ArcGIS Administrator Wizard to specify your software seat type, specify a license manager (if applicable), or authorize your Single Use software (if applicable). ArcGIS Desktop applications can be accessed from the Start > Programs > ArcGIS program group.

Note:

The ArcGIS Desktop setup allows you to perform a silent installation from a network server installation. This method gives you the ability to install ArcGIS Desktop without user interaction or prompts for deployment purposes. For more information, see Installing ArcGIS Desktop silently.
