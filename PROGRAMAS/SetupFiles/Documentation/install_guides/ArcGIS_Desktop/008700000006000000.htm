Minimum System requirements

Your computer must meet these minimum system requirements to install ArcGIS Desktop. For additional and updated requirements, see the System requirements page.

Visual Studio C++ Redistributable Requirement

ArcGIS Desktop requires Microsoft Visual C++ 2015-2019 Redistributable (x86) minimum version 14.22.27821. If the redistributable is not already installed, running setup.exe will install it before setup.msi is launched. To run setup.msi (without running setup.exe) the redistributable must already be installed.

.NET Support

ArcGIS Desktop requires Microsoft .NET Framework Version 4.5. If a minimum installation of .NET Framework 4.5 is not detected on your machine, the ArcGIS Desktop setup will not proceed.
