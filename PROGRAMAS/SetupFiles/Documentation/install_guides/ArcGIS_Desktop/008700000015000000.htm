Uninstalling ArcGIS Desktop

The ArcGIS software components can be easily uninstalled. Regardless of the software product type installed, the Add/Remove program item will be listed as ArcGIS Desktop.

Selecting ArcGIS Desktop 10.8 from the Add/Remove Programs dialog box provides the option to uninstall (Remove All) or add and remove installation components. For information on adding or removing installation components, see Adding ArcGIS Desktop installation components.

Uninstalling ArcGIS Desktop products

  1. Click Start > Control Panel (switch to Classic View, if necessary) and then Programs and Features.
  2. Select Programs > ArcGIS Desktop 10.8.
  3. Select Remove to uninstall ArcGIS Desktop from your machine.

To uninstall ArcGIS Desktop language packs, follow the steps above. Instead of selecting ArcGIS Desktop 10.8, select the ArcGIS Desktop language pack that you want to remove. If multiple ArcGIS Desktop language packs are installed, each language pack must be uninstalled separately.

Uninstalling Python

When Python is installed by the ArcGIS Desktop setup, it will be uninstalled when you uninstall ArcGIS Desktop.

How to perform an uninstallation of ArcGIS Desktop silently

To uninstall a product silently, use the following Windows Installer command:

msiexec /x <{product code}> /qb

For example, to uninstall ArcGIS Desktop 10.8 silently, use the following command line:

msiexec.exe /x {3DB5C522-636F-4FC2-9C38-298DBEBFD0BC} /qb
