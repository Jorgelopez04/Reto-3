Installing the ArcGIS extensions

The ArcGIS Data Interoperability for Desktop, ArcGIS Data Reviewer for Desktop, and ArcGIS Workflow Manager for Desktop are their own setup programs. To install, download and run the setups. The installation instructions are available with the download.

After installing, you must obtain an authorization file. For concurrent-use products, authorize the extension on your license manager. For single-use products, your authorization must contain the extension feature. See Obtaining an authorization file for more information.
